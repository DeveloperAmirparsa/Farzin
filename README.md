# Farzin Story Studio v7.0

استودیوی اختصاصی گالری طلا و سکه فرزین با منبع یکپارچه نرخ‌های TGJU و تابلو Full HD.

## اجرا در ویندوز

1. ZIP را کامل در یک پوشه تازه Extract کنید.
2. Node.js نسخه 18 یا جدیدتر نصب باشد.
3. داخل پوشه `farzin-story-studio` نوار آدرس File Explorer را انتخاب کنید، `cmd` بنویسید و Enter بزنید.
4. اجرا کنید:

   ```bash
   npm start
   ```

5. استودیو و خروجی استوری: `http://localhost:3000`
6. تابلو Full HD: `http://localhost:3000/board`
7. کانفیگ تابلو: `http://localhost:3000/board-config`
8. وضعیت فنی منبع و سرور: `http://localhost:3000/api/health`

پروژه وابستگی npm ندارد و به `npm install` نیاز نیست.

## اصلاح مشکل «اتصال به سرور محلی»

- سرور به‌صورت پیش‌فرض روی `0.0.0.0` گوش می‌دهد؛ یعنی فقط به localhost محدود نیست.
- اگر فایل `.env` قدیمی از نسخه‌های ۴ یا ۵ دارای `HOST=127.0.0.1` باشد، نسخه جدید آن مقدار loopback را خودکار به `0.0.0.0` ارتقا می‌دهد.
- پس از اجرای `npm start` در CMD، آدرس‌هایی با عنوان `Shop LAN` چاپ می‌شوند. برای تلویزیون یا دستگاه دیگر، همان آدرس را با `/board` باز کنید؛ مانند `http://192.168.1.10:3000/board`.
- اگر Windows Firewall سؤال کرد، دسترسی را برای شبکه Private مجاز کنید. کامپیوتر میزبان و تلویزیون باید به یک شبکه محلی وصل باشند.
- اگر تلویزیون با HDMI به همان کامپیوتر وصل است، `http://localhost:3000/board` کافی است.
- صفحه تابلو ابتدا پاسخ محلی را سریع دریافت می‌کند؛ دریافت نرخ از TGJU در پس‌زمینه انجام می‌شود. اگر فید در دسترس نباشد، وضعیت به آفلاین یا داده قدیمی تبدیل می‌شود و روی «اتصال به سرور محلی» نمی‌ماند.
- سرور و پنل مدیریت را به اینترنت عمومی port-forward نکنید؛ برای شبکه خصوصی مغازه طراحی شده است.

## منبع و روش دریافت قیمت

تمام قیمت‌های مورد استفاده در تابلو و استوری از فیدهای مورد استفاده وب‌سایت TGJU خوانده می‌شوند. سرور چند میزبان فید TGJU را بررسی می‌کند؛ دو میزبان اول به‌صورت هم‌زمان تست می‌شوند و در صورت شکست، دو میزبان جایگزین امتحان می‌شوند. این روش مانع وابستگی به یک زیردامنه می‌شود. دریافت خودکار روی سرور هر ۳۰ ثانیه انجام می‌شود و در صورت خطا، تلاش مجدد هر ۸ ثانیه خواهد بود. برای دریافت قیمت‌ها هیچ API key لازم نیست.

**محدودیت مهم:** TGJU یک API عمومی مستند و تضمین‌شده برای توسعه‌دهندگان منتشر نکرده است. برنامه از feed داخلی JSON به نشانی `ajax.json` که سایت برای ساخت داده‌های قیمتش استفاده می‌کند بهره می‌برد؛ این endpointها ممکن است در آینده تغییر کنند یا توسط بعضی شبکه‌ها مسدود شوند. اگر ساختار فید تغییر کند، parser برنامه نیز باید به‌روزرسانی شود. در قطع موقت، آخرین قیمت معتبر حفظ و به‌عنوان داده قدیمی مشخص می‌شود؛ قیمت ساختگی یا صفر جایگزین نمی‌شود.

قیمت‌های داخلی TGJU در ریال هستند و برنامه آن‌ها را بر ۱۰ تقسیم می‌کند تا تومان نمایش داده شود. انس جهانی و نفت برنت با واحد دلار نمایش داده می‌شوند.

## عیب‌یابی سریع

- اگر `/api/health` باز نمی‌شود، سرور اجرا نشده یا پورت ۳۰۰۰ توسط برنامه دیگری اشغال است.

## v6.2 board startup fix
If the board does not initialize, this release shows a useful visible startup or script-load error instead of keeping the original loading label. It also includes a `structuredClone` fallback for older smart-TV browsers. The board should still render when TGJU is unavailable; quote status then changes to offline/stale and the last valid prices remain visible.

Troubleshooting endpoints:
- `http://localhost:3000/api/health` — local server status and TGJU polling status.
- `http://localhost:3000/api/dashboard-data` — latest cached market snapshot and upstream errors.
- `http://localhost:3000/board` — Full HD live board.

After replacing the application folder, stop the old server with Ctrl+C, extract this release to a new folder, run `npm start`, then open the board with Ctrl+F5 to avoid a cached browser script.

## نسخه ۷.۰ · فهرست جامع دارایی‌ها و استقرار وب

### مدیریت دارایی‌ها

در پنل استوری و کانفیگ تابلو، فهرست دسته‌بندی‌شده دارایی‌ها اضافه شده است: طلا و آبشده، انواع سکه و حباب، نقره ۹۹۹ و ۹۲۵ و انس نقره، پلاتین و پالادیوم، فلزات پایه، ارزهای آزاد، رمزارزها (از جمله بیت‌کوین، اتریوم، تتر، ریپل، سولانا و ...)، نفت و انرژی، کالاهای جهانی، جفت‌ارزها، شاخص‌ها، صندوق‌ها و اوراق.

- برای افزودن دارایی، در هر جدول «افزودن نرخ/دارایی» را بزن و منبع را از فهرست انتخاب کن.
- برای هر نماد، عنوان، واحد، ضریب تبدیل و آیکون قابل ویرایش است.
- برای نماد سفارشی، منبع «نماد سفارشی TGJU» را انتخاب و شناسه پروفایل را در فیلد شناسه وارد کن. شناسه معمولاً بخش انتهایی نشانی پروفایل TGJU است؛ مانند `crypto-bitcoin` یا `silver_925`.
- گزینه ضریب تبدیل برای قیمت‌های ریالی که باید تومان شوند، ۱۰ است؛ برای قیمت‌های دلاری/جهانی، ۱.
- مسیر `/api/assets` فهرست کلیدهایی را که در آخرین پاسخ فید زنده موجود بوده‌اند، برمی‌گرداند و این کلیدها به گزینه‌های پنل افزوده می‌شوند.
- تمام نرخ‌ها و آیکون‌ها در هر دو خروجی استوری و تابلو قابل نمایش‌اند.

**محدودیت منبع:** صفحه رسمی TGJU دسته‌های گسترده‌ای از بازارها را برای ویجت معرفی می‌کند؛ از جمله طلا، سکه، ارز آزاد/سنا/نیما/دولتی، فلزات گران‌بها و پایه، نفت و انرژی، کالاها، فارکس، بورس‌های جهانی، رمزارزها، شاخص‌ها، سهام، اوراق، صندوق‌ها و ETFها. با این حال فید JSON عمومی `ajax.json` یک API توسعه‌دهندگان با تضمین و قرارداد ثابت نیست و الزاماً تمام بازارها و تمام شناسه‌های ویجت را در هر پاسخ خود ندارد. اگر شناسه در `/api/assets` یا فید موجود نباشد، ردیف به‌درستی خالی می‌ماند و باید از ویجت رسمی TGJU، منبع داده مجاز دیگر یا ورود دستی استفاده شود؛ برنامه نرخ جعلی تولید نمی‌کند.

### آیکون اختصاصی هر دارایی

برای هر ردیف در استوری و تابلو، آیکون Canvas برداری و هماهنگ با تم مشکی/طلایی رسم می‌شود. طلا، سکه، نقره/فلز، نفت، ارزها، جفت‌ارزها، سهام، کالاها و صندوق‌ها آیکون جدا دارند. برای رمزارزهای شناخته‌شده نیز نشانه‌های اختصاصی بیت‌کوین، اتریوم، تتر، ریپل، سولانا، BNB، کاردانو، دوج‌کوین و ترون در کنار عنوان قرار می‌گیرند. آیکون از نوع دارایی حدس زده می‌شود و در پنل قابل تغییر است.

### استقرار روی اینترنت

پروژه شامل `Dockerfile`، `.dockerignore`، `render.yaml`، `railway.json` و `Procfile` است. داده‌های تنظیمات در مسیر پایدار `FARZIN_DATA_DIR` ذخیره می‌شوند؛ در استقرار ابری این مسیر باید روی persistent disk/volume قرار بگیرد.

#### Render

1. پروژه را در GitHub قرار بده و در Render گزینه Blueprint را انتخاب کن.
2. فایل `render.yaml` به‌صورت خودکار سرویس Docker، health check و دیسک پایدار `/data` را تعریف می‌کند.
3. پس از اولین Deploy، رمز مدیر تولیدشده را در Environment سرویس ببین و نگهداری کن.
4. پنل مدیریت در ریشه سایت و `/board-config` با HTTP Basic Auth محافظت می‌شود؛ تابلو `/board` برای مشتریان عمومی است.

#### Railway

1. پروژه را به GitHub push کن و یک پروژه جدید از مخزن بساز.
2. Railway به کمک `railway.json` و `Dockerfile` پروژه را Build می‌کند.
3. از بخش Volumes یک Volume بساز و آن را روی `/data` Mount کن.
4. متغیرهای `FARZIN_DATA_DIR=/data`، `HOST=0.0.0.0`، `PORT=3000`، `ADMIN_USER=admin` و یک `ADMIN_PASSWORD` قوی تنظیم کن.
5. دامنه عمومی را فعال کن؛ مسیر health check برابر `/api/health` است.

#### متغیرهای محیطی ضروری

```env
PORT=3000
HOST=0.0.0.0
FARZIN_DATA_DIR=/data
ADMIN_USER=admin
ADMIN_PASSWORD=یک-رمز-طولانی-و-تصادفی
TGJU_FEED_URL=
```

`ADMIN_PASSWORD` را خالی نگذار و آن را در GitHub یا فایل‌های عمومی Commit نکن. صفحه استوری/مدیریت و API خواندن/نوشتن تنظیمات محافظت می‌شوند؛ تابلو عمومی از `/api/public-config` استفاده می‌کند و برای نمایش قیمت نیازی به ورود مدیر ندارد.

### نکته مهم در میزبانی

برای Render از دیسک پایدار تعریف‌شده در Blueprint و برای Railway از Volume استفاده کن؛ بدون فضای ذخیره‌سازی پایدار ممکن است تنظیمات پس از تعویض Container از بین بروند. برای چند نمونه هم‌زمان (multi-instance)، فعلاً این نسخه به یک نمونه سرور و یک volume مشترک طراحی شده است.
